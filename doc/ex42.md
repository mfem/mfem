# Example 42: ideal magnetohydrodynamics

Example 42 solves ideal MHD using discontinuous Galerkin elements and a
Rusanov flux. **Godunov-Powell (GP) sources and locally divergence-free (LDF)
projection are enabled by default**; use `-no-gp` or `-no-ldf` to disable them.
LDF projects the initial magnetic field and its time derivative within each
cell; normal magnetic traces may still jump across faces. No positivity
limiter is included.

Build with `make ex42` and run from the examples directory.

## Meshes and discretization

The mesh must be full-dimensional and fully periodic. For generated Alfven
wave meshes, `-dim 1`, `-dim 2` (default), and `-dim 3` select the dimension;
`-simp` selects simplices, `-tensor` selects tensor-product cells, and
`-dim 3 -prism` selects triangular prisms. A supplied mesh (`-m`) determines
the dimension itself and must match the problem's periodic domain.

| Dimension | Supported LDF cells | DG space |
| --- | --- | --- |
| 1 | Affine segments | P^k |
| 2 | Affine triangles; affine and bilinear quadrilaterals | P^k / Q^k |
| 3 | Affine tetrahedra, hexahedra, and triangular prisms | P^k / Q^k / P^k(triangle) x P^k(segment) |

Non-affine 3D cells, higher-order geometry, and pyramids are not supported
by LDF. Arbitrary polygons/polyhedra require subdivision into supported cells.
`MHDdim` counts velocity and magnetic components independently of the mesh
dimension, with `mesh_dim <= MHDdim <= 3`.

The current implementation uses MFEM's nodal DG bases with component-wise
scalar mapping. On non-affine mapped cells, the varying inverse Jacobian
complicates the physical divergence constraints. LDF support is therefore
primarily limited to affine cells, with the bilinear 2D quadrilateral case
handled separately. This limitation concerns the mapped approximation space,
not nodal versus modal coefficients alone; possible extensions are listed below.

Default flux and GP quadrature has algebraic precision **2k in cells and
2k+1 on faces**, following the choices studied by
[Huang and Shu for scalar conservation laws](https://archive.ymsc.tsinghua.edu.cn/pacm_download/113/1118-paper.pdf).
That scalar analysis is not an error theorem for this MHD scheme.
Inverse mass matrices and LDF projectors are precomputed and rebuilt by
`LDF_DG_GP_MHD::Update()` after mesh/space changes.

OpenMP parallelizes inverse-mass application and LDF projection when both
`MFEM_USE_OPENMP` and `MFEM_THREAD_SAFE` are enabled. Residual assembly within
each MPI rank remains serial.

CFL updates use the maximum characteristic speed from the latest residual
application (the last explicit RK stage), with a global maximum across MPI
ranks in `ex42p`. Each residual application resets the speed accumulator.

## Orszag-Tang vortex (`-p 1`, default)

```sh
./ex42 -p 1 -r 1 -o 2 -tf 0.05 -c 0.2 -no-vis
```

This 2D problem develops shocks. Without a suitable limiter, longer runs
can produce negative density or pressure. The reported L2 difference from
the initial condition is not an error against an exact solution.

## Smooth Alfven wave (`-p 2`)

The 2D data follow
[Wu and Shu, Section 4.1](https://arxiv.org/html/2604.23885v2#S4.SS1):
alpha = pi/6, rho = 1, p = 0.1, gamma = 5/3, on the periodic rectangle
[0, 2/sqrt(3)] x [0, 2]. The default mesh has 4 x 4 quadrilateral cells before
refinement. The exact solution is

```text
ca = cos(alpha), sa = sin(alpha)
phi = 2*pi*(x*ca + y*sa + t)
b = 0.1*sin(phi), z = 0.1*cos(phi)
v = (-b*sa, b*ca, z)
B = (ca-b*sa, sa+b*ca, z)
E = 0.1/(gamma-1) + 0.51
```

All eight conserved components are retained (2.5D MHD); LDF acts on B_x and
B_y. The period is one, and the default final time is **T=1**. This uses the
paper's initial data with the example's Rusanov DG method, rather than the
paper's complete PP-ES-DG method or its five-period simulation.

For degree-2 SSPRK3 convergence testing with GP and LDF enabled:

```sh
export OMP_NUM_THREADS=6
export OMP_PROC_BIND=close
export OMP_PLACES=cores

for r in 1 2 3; do
    ./ex42 -p 2 -r "$r" -o 2 -s 3 -tf 1 -c 0.2 -gp -ldf -no-vis
done
```

Here N = 4*2^r gives 8, 16, and 32 cells per direction. Each refinement
halves h; compute rates as `log2(error_coarse/error_fine)`. The reported
`B_perp L2 error` uses B_perp = -B_x*sin(alpha)+B_y*cos(alpha); the full-state
L2 error is also reported. Degree 2 with SSPRK3 measures third-order fully
discrete convergence. Reduce the CFL or fixed time step to assess temporal
error. A positive `-dt` overrides CFL stepping; `-tf` overrides the final time.

### One- and three-dimensional waves

The 1D wave uses [0,1], alpha=0, and all eight state components. The 3D wave
uses the periodic cube [0,sqrt(3)]^3 and

```text
n  = (1,1,1)/sqrt(3)
e1 = (-1,1,0)/sqrt(2)
e2 = (-1,-1,2)/sqrt(6)
phi = 2*pi*(dot(n,x)+t)
v = 0.1*(sin(phi)*e1 + cos(phi)*e2)
B = n+v
rho = 1, p = 0.1, E = 0.1/(gamma-1)+0.51
```

Both are exact, spatially periodic smooth solutions with period one and no
artificial forcing. The 3D wave generalizes the paper's 2D data; its reported
B_perp is dot(B,e1).

```sh
./ex42 -p 2 -dim 1 -r 2 -o 2 -s 3 -tf 1 -no-vis
./ex42 -p 2 -dim 3 -r 0 -o 2 -s 3 -tf 1 -no-vis
./ex42 -p 2 -dim 3 -simp -r 0 -o 2 -s 3 -tf 1 -no-vis
./ex42 -p 2 -dim 3 -prism -r 0 -o 2 -s 3 -tf 1 -no-vis
```

The generated 3D mesh starts with 4 cells per direction, subdivided into six
tetrahedra per cube for `-simp` or two prisms for `-prism`. **No 3D evolution
or convergence study has been run**; validation used projector and analytic
PDE checks.

## MPI support

`ex42p` adds MPI support for the same problems and GP/LDF discretization.
Build with `make ex42p` in an MPI-enabled MFEM build, then run, for example:

```sh
mpirun -np 2 ./ex42p -p 2 -r 1 -o 2 -s 3 -tf 1 -no-vis
```

## Recorded convergence results

These previously recorded 2D results predate the 1D/3D extensions and have
not been rerun for those changes. They use **k=2, SSPRK3, GP and LDF, CFL=0.2,
and T=1**, with N x N quadrilateral cells. For this degree, face precisions
2k and 2k+1 select the same Gauss rule.

Measured on 2026-10-16 in WSL2 with Intel `icpx` 2026.1.1, MFEM 4.10.1,
double precision, a Release build (`-O3 -DNDEBUG -fiopenmp`), and six OpenMP
threads (bad OMP efficiency, see the next section). OpenMP and thread safety were enabled; MPI and METIS were disabled.

| 8 | 4,608 | 5.59646567e-04 | — | 3.98604635e-03 | — | 206 | 2.164 |

Timings cover time integration only and do not measure OpenMP speedup.

## Remaining limitations

General non-affine LDF projection is not implemented for the current mapped
nodal DG spaces. Two possible extensions are:

1. Use a broken H(div) magnetic space with the contravariant Piola mapping
   (e.g. simplex BDM), preserving reference divergence-free fields without
   enforcing intercell normal continuity. A divergence-free subspace or
   projection is still required. Quadrilateral BDM enrichments extend beyond
   [Q^k]^2. See [Piola mapping](https://arxiv.org/abs/2008.06429) and
   [BDM spaces](https://www-users.cse.umn.edu/~cockburn/lecture_notes/HDG-4.pdf).
2. Build locally divergence-free modal polynomials directly in physical
   coordinates, with cell-specific bases and integration. Changing only the
   basis of the same mapped space from nodal to modal does not remove the
   geometry restriction.

OpenMP residual assembly requires revised scheduling and data ownership:
current face assembly shares mutable transformations/integrator state and
can write concurrently to the same element. Private objects and buffered
face contributions could resolve this without changing flux interfaces.
MPI time stepping is supported; OpenMP currently accelerates only
inverse-mass application and LDF projection within each rank.
